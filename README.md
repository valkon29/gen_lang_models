# Ппроект по курсу: Генеративные языковые модели

Тема: **«Домашние растения»**. Дообучаем `Qwen/Qwen2.5-3B-Instruct` отвечать на вопросы
по уходу за комнатными растениями на русском языке.

## Структура

```
./
├── checks.py               # автопроверки ответов (язык, формат, повторы, длина)
├── test_checks.py          # юнит-тесты проверок
├── houseplants_full.ipynb  # ЕДИНЫЙ ноутбук: весь пайплайн от бейзлайна до оценки
├── data/
│   ├── seed_train.jsonl   # 41 курируемый пример (messages-формат)
│   └── eval_questions.jsonl # 15 отложенных вопросов
└── outputs/                # итоговые артефакты финального прогона (метрики, график, ответы)
    ├── baseline_answers.jsonl
    ├── sft_answers.jsonl
    ├── judge_scores.json
    ├── metrics.json
    └── metrics_plot.png
```

## Воспроизведение (Google Colab, T4)

Весь пайплайн — в одном самодостаточном ноутбуке **`houseplants_full.ipynb`**:

1. Загрузите его на [colab.research.google.com](https://colab.research.google.com)
   (`Файл → Загрузить ноутбук`).
2. `Среда выполнения → Сменить среду выполнения → T4 GPU`.
3. `Среда выполнения → Выполнить всё`.
4. На шаге синтетической генерации данных ноутбук запросит **API-ключ YandexGPT**
   в скрытом поле (или задайте переменную окружения `LLM_API_KEY` перед запуском).

Загружать файлы не нужно: `checks.py`, seed-данные и eval-вопросы встроены в ячейки.
Промежуточные результаты (бейзлайн, `train.jsonl`, адаптер, ответы, метрики) пишутся
на диск, поэтому при обрыве сессии повторный запуск продолжится с места обрыва.
В конце ноутбук сам скачивает `houseplants-lora.zip` (веса) и
`houseplants-artifacts.zip` (данные, ответы, метрики, график).

Архитектура: дообучаемая модель — Qwen2.5-3B (QLoRA); генератор данных —
DeepSeek v4 flash (API Yandex Cloud); судья — YandexGPT (API, без квантования).
Все три модели — из разных семейств, за счёт этого нет смещения.

Суммарное время на T4: ~1–1,5 часа (самый долгий шаг — QLoRA-обучение;
генерация данных через API — ~15–20 минут).
